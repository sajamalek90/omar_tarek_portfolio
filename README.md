🎨 Customization
Updating Content

Personal Information: Edit the hero section and about section in index.html
Skills: Modify the skills sections to reflect your expertise
Experience: Update the experience timeline with your professional background
Projects: Replace project cards with your own work and descriptions

Styling Changes

Colors: Modify the gradient colors in styles.css
cssbackground: linear-gradient(135deg, #000727 0%, #4867ff 75%);

Typography: Change fonts in the body selector
Layout: Adjust grid layouts and spacing as needed

Adding New Sections

Add new HTML sections following the existing structure
Update navigation links in the header
Apply consistent styling using existing CSS classes

📱 Responsive Design
The portfolio is fully responsive with breakpoints at:

Desktop: 1200px+ (full layout)
Tablet: 768px-1199px (adjusted grid)
Mobile: <768px (single column, simplified navigation)
