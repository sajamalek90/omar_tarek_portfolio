Dynamic Row-Level Security (RLS) in Power BI

This project demonstrates the implementation of Dynamic Row-Level Security (RLS) in Power BI to control data access based on the logged-in user's email. The solution is built on a structured Semantic Model that connects the INFO Sec security table with the dim_Product and fact_InternetSales tables. The security table stores each employee's email and assigned product subcategory, while the relationships allow the security filter to propagate through the model and restrict the underlying sales data. The RLS logic uses DAX and USERPRINCIPALNAME() to dynamically identify the logged-in user and retrieve their assigned subcategory. The Semantic Model was published to Power BI Service, where the RLS role was configured and validated using Test as Role.

Key Insights:

. Semantic Model: Designed relationships between the security, product, and sales tables to enable dynamic filter propagation.


. Dynamic User Filtering: Identifies the logged-in user using USERPRINCIPALNAME().


. Subcategory-Level Security: Each employee can only access products within their assigned subcategory.


. Centralized Security Table: Employee permissions are managed through the INFO Sec table.


. Power BI Service: Published the Semantic Model and configured the RLS role in the Service.


. Security Validation: Tested the role using Test as Role to verify that users only see authorized data.
